# windows-use-mcp

MCP server (stdio) that sees, reads and drives Windows desktop programs: UI Automation, Win32
controls, screenshots (covered windows and other virtual desktops too), keyboard, mouse,
image search and clipboard. Windows only.

```
npx -y windows-use-mcp
```

Setup for each client and the tool list: https://github.com/KaburiCoder/agent-plugins/tree/main/plugins/windows-use
